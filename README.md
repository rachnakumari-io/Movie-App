# 🎬 Movie App

A modern movie discovery application built with **React** and **Vite** that allows users to browse popular movies, search for titles, and manage a personal favorites collection.

## ✨ Features

- 🔍 Search for movies by title
- 🎥 Browse popular movies
- ❤️ Add and remove movies from favorites
- 💾 Favorites persist during the session
- 📱 Responsive user interface
- ⚡ Fast performance with Vite

## 🛠️ Built With

- React
- Vite
- React Context API
- TMDB API
- CSS3

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/rachnakumari-io/Movie-App.git
```

### Install dependencies

```bash
npm install
```

### Create an environment file

Create a `.env` file in the project root and add your TMDB API key:

```env
VITE_API_KEY=YOUR_TMDB_API_KEY
```

### Run the application

```bash
npm run dev
```

The application will be available at:

```
http://localhost:5173
```

## 📌 API

This project uses **The Movie Database (TMDB) API** to fetch movie information.
